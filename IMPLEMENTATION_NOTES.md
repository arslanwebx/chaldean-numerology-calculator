# Implementation Notes

Built July 11, 2026 as a root-level Next.js App Router application. The repository was empty apart from `.gitignore`.

## Architecture

- Static educational pages are React Server Components. The calculator, navigation menu, and contact form are the focused client components.
- `src/lib/numerology.ts` owns deterministic name and Gregorian date logic. `src/data/chaldean.ts` is the single immutable letter map.
- Calculator inputs remain in React state only. They are never requested by an API, URL, cookie, analytics event, or browser storage.
- Site identity and optional integrations are environment-driven through `src/config/site.ts`.
- The typed post registry contains the three substantive canonical guides. `/blog/` is indexable and presents responsive article cards without duplicating guide content at competing URLs.

## Decisions and limitations

- CSP allows Next.js inline bootstrap scripts and inline styles needed by the framework, while restricting all origins to self. Re-test CSP if Google services are enabled.
- The single-process contact limiter is deliberately modest. Add CDN or Hostinger edge protection for distributed abuse.
- Analytics and ads remain disabled. The ad component intentionally has no network script or slot ID.
- SVG is used for icons. The Open Graph PNG is generated by Next.js at request/build time.
- Legal copy is tailored but requires qualified legal review before commercial launch.
